# Urban Development Official Law Seeds

Place official JSON/XML files for these laws here when provided:

- urban_development_law.json or urban_development_law.xml
- urban_development_enforcement_decree.json or urban_development_enforcement_decree.xml
- urban_development_enforcement_rule.json or urban_development_enforcement_rule.xml

Each file must have a matching `manifest.json` or separate manifest file that points to the source file. Do not invent law text, article numbers, or criteria.
